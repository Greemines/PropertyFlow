# PropertyFlow

**A real-time real estate management platform for Pakistani agencies.**

PropertyFlow helps small and medium real estate agencies manage listings, clients, leads, property visits, deals and agent commissions from one web application. The server enforces the agency's business rules: visits cannot clash, a property cannot be sold twice, leads follow a fixed path, and commission is calculated by property type. Agents see status changes and new client matches live, and every property appears on an interactive city map.
